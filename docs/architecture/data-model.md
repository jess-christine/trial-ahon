# Proposed analytical model and current source coverage

The target dimensions and facts are `dim_lgu`, `dim_cmci_indicator`, `fact_cmci_indicator`, `fact_population`, `fact_ldrrmf`, and `fact_earthquake_event`. The owner has set the analysis geography to cities and municipalities; the former barangay population fact is not part of this target. `fact_population` now represents one PSA city/municipality source path and census year, with a nullable PSGC match.

The Silver mappings added for the available sources prepare values for that model while preserving lineage. They do not rename or manufacture Gold keys. PSGC codes are available from PSGC and the reviewed `lgu_master`; CMCI uses the approved `cmci_lgu_map`. BLGF and PSA Gold matches use the approved exact LGU + province names rule against active `lgu_master`; unmatched and ambiguous records remain null. PHIVOLCS event geography is assigned in Gold only through the approved approximate Geoportal polygon source; status and null confidence remain explicit.

PSA population is available at national, region, province, and city/municipality levels in the documented 2024 extract. Gold uses only city/municipality rows and matches exact LGU and province names to the active reviewed `lgu_master`. Unmatched and ambiguous records retain their source geographic path and have null `psgc_code`; no name similarity or population allocation is used. Other PSA hierarchy rows stay in Silver for coverage/audit and are not mixed into the Gold fact.

The current Gold build creates `dim_lgu`, `dim_cmci_indicator`, `fact_cmci_indicator`, `fact_population`, `fact_ldrrmf`, and `fact_earthquake_event`. `fact_population` retains each city/municipality source row, linking only unique exact LGU + province name matches; it is keyed by the PSA `geographic_location` and year so unmatched rows remain observable. `fact_ldrrmf` includes city and municipality rows only; province lines remain in Bronze and Silver, and the Gold quality run counts this intentional exclusion. LDRRMF utilization follows the approved total expenditure / total appropriation formula and remains null for zero or missing denominators. PHIVOLCS match status reflects unique spatial assignment; confidence remains null because the approximate boundary method has no calibrated confidence scale.

Experimental Platinum v1 now calculates those outputs using owner-approved assumptions. These are an analytical prototype, not calibrated operational thresholds: city/municipality population and earthquake attributes use within-cohort percentiles; activity combines event count, mean magnitude, and inverse mean centroid distance over five rolling years; risk categories and vulnerability screening use tertiles; CMCI capacity averages within-indicator percentiles across the approved indicator set; LDRRMF utilization is total expenditure divided by total appropriation times 100; and missing components remain null. The owner approved the supplied descending preparedness-gap sort. Since risk spans 0–10,000 while preparedness spans 0–200, that gap must not be interpreted as a common-scale deficit. Approximate Geoportal boundaries are required for earthquake assignment and their limitations remain material.
